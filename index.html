Backup na nuvem (Supabase)

Opcional. Se preencheres, os dados são guardados no Supabase e não se perdem se acontecer algo ao iPhone. Deixa em branco para funcionar só localmente.

SQL para criar a tabela (corre uma vez no Supabase) 
create table if not exists items (
  id uuid primary key,
  title text,
  area text,
  type text,
  priority text,
  due text,
  status text,
  notes text,
  url text,
  deleted boolean default false,
  "createdAt" bigint,
  "updatedAt" bigint
);
alter table items enable row level security;
create policy "anon full" on items
  for all using (true) with check (true);

A política acima deixa qualquer um com a anon key ler/escrever. Serve para uso pessoal. Para multi-utilizador, usa Auth + RLS por user_id.
